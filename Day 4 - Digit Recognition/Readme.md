# Handwritten Digit Recognition with Streamlit

## Overview

This project provides a web application for handwritten digit recognition using a pre-trained neural network model. The application allows users to upload an image of a handwritten digit, which is then classified by the model. The result is presented in a user-friendly format.

## Features

**Image Upload**: 
Users can upload an image file in JPG, JPEG, or PNG format.

-**Digit Classification**: The uploaded image is classified into one of the ten digit classes (0-9).

-**User-Friendly Interface**: The application is designed to be intuitive and easy to use.

## Requirements

To run this application, you'll need the following Python libraries:

-`streamlit`-`numpy`-`tensorflow`-`PIL`-`io`

You can install these libraries using pip:

```bash
pip install streamlit numpy tensorflow pillow
```

## Run the Application

**Run the Application**: Open a terminal and navigate to the directory containing digitRecognition.py. Run the following command:

```bash
streamlit run digitRecognition.py
```
**Open the App**: Streamlit will provide a local URL in the terminal (e.g., http://localhost:8501). Open this URL in your web browser to access the application.
