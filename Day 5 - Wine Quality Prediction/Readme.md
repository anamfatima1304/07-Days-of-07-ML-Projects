# Wine Quality Prediction App

## Overview

This application is designed to predict the quality of wine based on its physicochemical features using a Decision Tree Classifier. The app provides a user-friendly interface where users can input various features of the wine, and it will output the predicted quality. 

## Features

- **User Input**: Enter features such as Fixed Acidity, Volatile Acidity, Residual Sugar, etc.
- **Prediction**: Get a prediction of the wine quality based on the input features.
- **Visualization**: Displays an image based on the predicted quality of the wine.

## Requirements

- Python 3.x
- Streamlit
- NumPy
- Joblib

## Setup

1. **Clone the Repository**

   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Run the Streamlit App**

Navigate to the directory containing app.py and run the following command:

```bash
streamlit run app.py
```

3. **Open the App**

Open the provided URL in your browser (usually http://localhost:8501).

## Usage

#### Enter Features

Input the following features of the wine:

- Fixed Acidity
- Volatile Acidity
- Residual Sugar
- Chlorides
- Total Sulfur Dioxide
- Density
- pH
- Alcohol

#### Get Prediction

Click the "Predict Wine Quality" button to see the predicted quality of the wine. The result will also display an image representing the predicted quality.
